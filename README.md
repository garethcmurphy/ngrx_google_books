# NgRx Workshop: Google Books Example 📚✨  

This repository provides a hands-on workshop for learning **NgRx** by implementing a state management system for a **Google Books** example application. It demonstrates key concepts such as actions, reducers, selectors, and effects.

---

## Features ✨  

- **NgRx State Management**: Learn how to manage state in Angular applications.  
- **Google Books API Integration**: Query and display books using the Google Books API.  
- **Modular Structure**: Example application showcasing best practices for scalable architecture.  

---

## Prerequisites 🛠️  

- **Node.js** and **npm** installed.  
- Angular CLI installed globally:  
  npm install -g @angular/cli  

---

## Installation  

1. Clone the repository:  
git clone https://github.com/your-username/ngrx-workshop-google-books.git  
cd ngrx-workshop-google-books  

2. Install dependencies:  
npm install  

3. Run the development server:  
npm start  

4. Open the application in your browser:  
http://localhost:4200  

---

## Usage 🔧  

1. Search for books using the search bar powered by the **Google Books API**.  
2. View a list of books retrieved from the API.  
3. Add books to a "My Collection" list, demonstrating state management with NgRx.  

---

## File Structure 📂  

- `src/`: Angular source code.  
  - `app/`: Main application code, including modules, components, and services.  
  - `store/`: NgRx store implementation, including actions, reducers, effects, and selectors.  
- `README.md`: Documentation for this repository.  

---

## Learning Objectives 🎓  

1. Understand the core components of NgRx:
   - **Actions**: Define events that describe state changes.  
   - **Reducers**: Handle state transitions based on actions.  
   - **Selectors**: Query specific slices of state.  
   - **Effects**: Handle side effects such as API calls.  

2. Apply NgRx to real-world scenarios by integrating it with the **Google Books API**.
